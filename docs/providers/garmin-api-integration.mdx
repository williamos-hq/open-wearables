## Official integration status

The official Garmin OAuth, callback, webhook, vendor-read, manual-sync, and
backfill routes are unavailable in the WilliamOS fork. They return `404` and do
not enqueue background work.

Garmin is import-only here. A separately deployed private bridge owns Garmin
Connect login, MFA, encrypted sessions, polling, cooldowns, overlap windows,
and cursors. Open Wearables receives only authenticated, user-scoped health and
activity observations.
